# The City Beneath Us

A 60-second, 9:16 animated short project built with browser-native Canvas, CSS, JavaScript and Web Audio. It uses no external API, no API key, no subscription and no paid asset provider.

## Run it
Open `index.html` in a modern browser (Chrome recommended). Tap **Play** to preview, **Export WebM** to render a 60-second WebM locally, or **Narration voice** to hear the current scene using a voice already installed on your device.

## Important export notes
- Export includes the original ambient soundtrack generated locally with Web Audio.
- Browser speech synthesis is a separate phone/browser playback feature and is **not** embedded in the exported file. The narration text is included as timed, word-highlighted captions.
- If you want spoken narration embedded, record the narration separately with your device's built-in screen/audio recorder or add a voice track in a free editor. Do not enter paid API keys or enable paid services.

## Production tools and cost policy
- **HyperFrames** is free/open-source under Apache-2.0 and can be used as a local HTML-to-video rendering route on a computer. This project does not require it to preview or export from the browser.
- **Blender** is free/open-source. It is optional; this build uses original 2D vector/canvas art instead of requiring a 3D render.
- **OpenMontage** is open-source, but its full agent workflow may call optional third-party providers. Do not configure any provider or API key that requires payment. This browser project avoids those providers.
- **ReelMimic** is not required to render this original story. No reference video is copied; the project uses an original cinematic look.

No paid plan, paid model, stock subscription, API credit or trial is required by this project.

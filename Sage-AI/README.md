# Sage AI

Sage is a personal AI assistant designed for desktop and iPhone.

## Project goals
- Natural text conversations
- Voice input and spoken replies
- Helpful conversation memory
- Web search
- Screen assistance where supported
- Image understanding and image generation
- Optional connections to supported apps
- Explicit approval before any external action

## Safety
Sage must never perform an external action based only on a spoken phrase. It must show the proposed action, wait for a deliberate physical approval, provide a cancel option, and require a second confirmation for important actions.

## Platforms
The interface is planned for desktop and iPhone. Some background voice, floating-window, and screen-sharing features depend on operating-system and browser support.

## Build status
Planning and repository setup. No production assistant functionality has been implemented yet.

## Planned phases
1. Prepare the project
2. Visual design
3. Assistant intelligence
4. Assistant capabilities
5. Safety, testing, and launch

## Cost target
Use free GitHub and Cloudflare services where possible. Free-tier limits and any features requiring paid services must be identified before use.
